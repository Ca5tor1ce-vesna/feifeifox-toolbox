# 绯绯狐工具箱

b站：@syllo椭圆 出品的《崩坏：星穹铁道》配速工具箱。

## 能做什么

- **全角色行动轴**：选角色就能出轴，算速度、拉条、额外回合、插大和回能；队里有欢愉角色时自动显示阿哈时刻；选好关卡，敌人也会上轴出手，伤害和生命一起算。
- **轴分享**：把排好的轴存成一张分享图发给别人；收到的人在首页「导入分享码」选这张图，或在行动轴里粘贴分享码，就能预览、套用这条轴。
- **手动排轴**：像在游戏里一样一步步打，轮到我方出招、能开终结技时停下来让你选；在行动轴里点开卡片，选「从这继续手操」，就带着前面的走法接着打。
- **角色**：导入 UID、文件或战绩分享图，查看角色、光锥和遗器，算出和游戏里一样的面板。
- **遗器**：五星遗器库，校验词条、给角色穿脱，查看套装效果。
- **编队**：整理常用队伍，可一键导入到行动轴。
- **攻略合集**：出分视频按期数和玩法找，选好编队只看你抄得了的作业。
- **角色顶分**：低配通关阵容，数据来自 The Herta。

## 下载和使用

1. 到 [Releases](https://github.com/Ca5tor1ce-vesna/feifeifox-toolbox/releases) 下载最新的 `feifeifox-toolbox-v版本号-portable.zip`（免安装版）。
2. 解压到任意文件夹（路径带中文或空格也没问题）。
3. 双击 `FeifeiFoxToolbox.exe`。不用安装任何东西（用 Windows 自带的 WebView2 显示界面）。

也可以在 B站直接打开网页版（B站 Toy），不用下载；网页版的存档在浏览器里，换设备前用左下角的「导出存档」备份。

第一次打开时，Windows 可能提示「已保护你的电脑」，因为 exe 没有数字签名。点「更多信息」再点「仍要运行」即可。你的配装和队伍存在解压目录里的 `userdata/`，换新版本时把这个文件夹复制过去就不会丢；以前版本的 `userdata` 直接能用。

更多说明见压缩包里的 `使用说明.html`，每个版本改了什么见 [修改记录](修改记录.md)。

## 隐私与统计

电脑版（exe）会发送匿名的使用次数，帮作者知道大家最常用哪些功能和角色：打开了哪个功能、模拟里用了哪些角色、用的是哪个版本、哪里出了错。不收集游戏账号和 UID、存档和配装、截图、你输入的文字，也不记录 IP 地址。第一次打开时会说明一次，选「不参与」就不发送，之后随时可以在左下角的「隐私与统计」里关掉。

「问题反馈」可以直接发给作者，只在你点「发送给作者」时才发。B站网页版不发送任何统计，反馈照旧复制诊断码或导出成文件。
