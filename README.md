# 绯绯狐工具箱（feifeifox-toolbox）

崩坏：星穹铁道的实用工具箱：配速查询、行动轴、角色与遗器、抽卡规划、角色顶分等。

本仓库只放**公开发布**的安装包，方便下载。开发在私有仓库进行。

## 下载

打开 [Releases](https://github.com/Ca5tor1ce-vesna/feifeifox-toolbox/releases/latest) 下载最新版：

- **免安装版（Windows）**：解压后双击 `FeifeiFoxToolbox.exe`（系统一般自带 WebView2；没有就装微软的 WebView2 运行时）。
- **网页版**：解压后用浏览器或静态站点打开 `index.html`（建议用本地静态服务 / 托管，不要只依赖双击 file 协议）。

## 数据与升级

- 绿色版的个人数据在解压目录的 `userdata/`。升级时把旧的 `userdata` 整份拷到新版本即可；也可用应用里的「导出/导入存档」。
- 角色顶分数据来自 The Herta；安装包内带快照，刷新在线数据需要联网。
